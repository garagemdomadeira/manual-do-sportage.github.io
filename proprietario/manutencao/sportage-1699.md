# Kia Sportage: 2. Controle de emissão evaporativa (incluindo ORVR: Recuperação de Vapores de Combustível a bordo durante a recarga)

[Início](../../index.md) / [Manual do proprietário do Kia Sportage SL](../sportage-1236.md) / [Manutenção](sportage-1629.md) / [Sistema de controle de emissão](sportage-1697.md) / 2. Controle de emissão evaporativa (incluindo ORVR: Recuperação de Vapores de Combustível a bordo durante a recarga)

O Sistema de Controle de Emissão Evaporativa é projetado para prevenir a liberação de vapores de combustível na atmosfera.

(O sistema ORVR é projetado para permitir que os vapores do tanque de combustível sejam absorvidos em uma câmara de absorção durante a recarga na estação de combustível, evitando a liberação de vapores de combustível na atmosfera.)

**Câmara de Absorção**

Os vapores de combustível gerados dentro do tanque de combustível são absorvidos e armazenados na câmara de absorção a bordo. Quando o motor está em funcionamento, os vapores de combustível absorvidos na câmara são sugados para a câmara de ondulação através do válvula controladora de purga (PCSV).

**Válvula Controladora de Purga (PCSV)**

A válvula controladora de purga é controlada pelo Módulo de Controle do Motor (ECM); quando a temperatura do líquido de resfriamento do motor é baixa durante o funcionamento em idle, a PCSV fecha para impedir que os vapores de combustível evaporados sejam levados para o motor. Após o aquecimento do motor durante o uso normal, a PCSV abre para introduzir os vapores de combustível evaporados para o motor.
