# Kia Sportage: 1. Sistema de ventilação positiva do caixa de câmbio

[Home](../../index.md) / [Manual do proprietário Kia Sportage SL](../sportage-1236.md) / [Manutenção](sportage-1629.md) / [Sistema de controle de emissões](sportage-1697.md) / 1. Sistema de ventilação positiva do caixa de câmbio

O sistema de ventilação positiva do caixa de câmbio é empregado para prevenir a poluição do ar causada pelos gases de sobreaquecimento que são emitidos do caixa de câmbio. Este sistema fornece ar fresco e filtrado ao caixa de câmbio através do tubo de admissão de ar. Dentro do caixa de câmbio, o ar fresco mistura-se com os gases de sobreaquecimento, que então passam pelo valevão PCV para o sistema de admissão.
