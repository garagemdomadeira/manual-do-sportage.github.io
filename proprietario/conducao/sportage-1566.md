# Kia Sportage: Quando o ECO Ativo é ativado

[Home](../../index.md) / [Manual do proprietário do Kia Sportage SL](../sportage-1236.md) / [Dirigindo seu veículo](sportage-1508.md) / [Sistema ECO Ativo](sportage-1564.md) / Quando o ECO Ativo é ativado

- A aceleração pode ser ligeiramente reduzida mesmo quando você pressionar completamente o acelerador.
- O desempenho do ar condicionado pode ser limitado.
- O padrão de trocas do transmissor automático pode mudar.
- O ruído do motor pode ficar mais alto.

As situações acima são condições normais quando o sistema ECO Ativo é ativado para melhorar a eficiência do combustível.
