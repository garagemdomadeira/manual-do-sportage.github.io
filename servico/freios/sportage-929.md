# Kia Sportage: Interruptor ESC OFF: Descrição e Operação

[Home](../../index.md) / [Manual de Serviço e Reparo do Kia Sportage SL](../sportage-482.md) / [Sistema de Freios](sportage-894.md) / [Sistema ESC (Controle Estático Eletrônico)](sportage-915.md) / Interruptor ESC OFF: Descrição e Operação

## Descrição

1. O interruptor ESC OFF é usado pelo usuário para desligar o sistema ESC.

2. O lampada ESC OFF está acesa quando o interruptor ESC OFF está engajado.
