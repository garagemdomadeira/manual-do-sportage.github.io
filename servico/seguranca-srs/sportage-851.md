## Ferramentas Especiais de Serviço

| Ferramenta (Número e Nome) | Ilustração | Uso |
| --- | --- | --- |
| Ferramenta de Deslocamento 0957A-34100A |  | Ferramenta para deslocamento do airbag. |
| Adaptador de Deslocamento 0957A-38510 |  | Usar com a ferramenta de deslocamento. (DAB) |
| Adaptador de Deslocamento 0957A-3Q100 |  | Usar com a ferramenta de deslocamento. (PAB) |
| Adaptador de Deslocamento 0957A-3F100 |  | Usar com a ferramenta de deslocamento. (SAB) |
| Adaptador de Deslocamento 0957A-3S100 |  | Usar com a ferramenta de deslocamento. (CAB) |
| Adaptador de Deslocamento 0957A-38500 |  | Usar com a ferramenta de deslocamento. (CAB, BPT, APT) |
| Manequim 0957A-38200 |  | Simulador para verificar a resistência de cada fio de alimentação. |
| Adaptador de Manequim 0957A-3F000 |  | Usar com o manequim (SAB) |
| Adaptador de Manequim 0957A-2G000 |  | Usar com o manequim (DAB, PAB, CAB, BPT, APT) |

DAB : Airbag do Motorista

PAB : Airbag do Passageiro

SAB : Airbag Lateral

CAB : Airbag de Teto

BPT : Pretensores de Cinto de Segurança

APT : Pretensores de Anilha
