# Kia Sportage: Módulo de Controle do SRS (SRSCM): Descrição e Operação

## Descrição

O principal propósito do Módulo de Controle do SRS (Supplemental Restraints
System Control Module - SRSCM) é discriminar entre um evento que justifica
a ativação do sistema de retenção e um evento que não justifica. O SRSCM deve
decidir se deve ativar o sistema de retenção ou não. Após determinar que
pretensores e/ou inflamadores de airbags são necessários, o SRSCM deve
fornecer energia suficiente aos pretensores e inflamadores de airbags para
iniciar a ativação.

O SRSCM determina que um impacto pode exigir a ativação dos pretensores e
airbags a partir de dados obtidos de sensores de impacto e outros componentes
em conjunto com uma função de segurança.

O SRSCM não estará pronto para detectar um acidente ou para ativar
os dispositivos de retenção até que as sinais na circuitos do SRSCM se
estabilizem.

É possível que o SRSCM ative os dispositivos de segurança
de retenção em aproximadamente 2 segundos, mas está garantido a
funcionamento completo após a conclusão do teste de validação.

O SRSCM deve executar uma rotina diagnóstica e acender um
indicador de prontidão do sistema ao ligar a chave. O sistema deve executar
uma rotina diagnóstica contínua e fornecer anúncio de falha através de um
indicador de lâmpada de advertência em caso de detecção de falha. Uma
interface de comunicação diagnóstica serial será utilizada para facilitar o
serviço do sistema de controle de retenção.
