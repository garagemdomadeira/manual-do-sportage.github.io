# Kia Sportage: Linha de refrigerante: Procedimentos de reparo

[Home](../../index.md) / [Manual de Serviço e Reparo do Kia Sportage SL](../sportage-482.md) / [Aquecimento, Ventilação, Ar Condicionado](sportage-1181.md) / [Sistema de Ar Condicionado](sportage-1186.md) / Linha de refrigerante: Procedimentos de reparo

## Troca

1. Descarregar o refrigerante do sistema de refrigeração.

2. Substituir o tubo ou mangueira danificado.

   > **Cuidado**
   >
   > - Capar imediatamente as conexões abertas para evitar a entrada de umidade ou sujeira no sistema.

3. Ajustar a junta do parafuso ou do parafuso de acordo com a torque especificada.

   > **Cuidado**
   >
   > - As conexões não devem ser ajustadas mais apertadas do que a torque especificada.

   | Parte ajustada | N.m | Kgf.m | lb-ft |
   | --- | --- | --- | --- |
   | Condensador - Mangueira de descarga | 3,9~9,8 | 0,6~1,0 | 4,3~7,2 |
   | Condensador - Tubo líquido | | | |
   | Compressor - Mangueira de descarga | 19,6~24,5 | 2,0~2,5 | 14,4~18,0 |
   | Compressor - Mangueira de sucção | | | |
   | Valvula de expansão - Evaporador | 11,8~14,7 | 1,2~1,5 | 8,7~10,9 |

4. Evacuar o ar do sistema de refrigeração e carregar o sistema com refrigerante.

   ```
   Quantidade especificada: 550 ± 25g (19,4 ± 0,88oz)
   ```

5. Inspeção de vazamento de refrigerante.

   Utilize um detector de vazamento de gás para verificar a presença de vazamento de refrigerante.

6. Inspeção da operação do ar condicionado.
