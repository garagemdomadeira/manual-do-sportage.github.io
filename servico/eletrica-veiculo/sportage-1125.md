## Diagnóstico

| Problema | Causa Possível | Solução |
| --- | --- | --- |
| Não está parando | O dispositivo Bluetooth do carro não está em modo de descoberta | Entrar no modo de parada Bluetooth (descobrindo) |
| O telefone do usuário está em modo Bluetooth desligado | O telefone do usuário deve ter o Bluetooth ligado |  |
| Tentativa de parar outros sistemas Bluetooth | Verifique o nome e o endereço do dispositivo Bluetooth (12 palavras) para tentar parar Ex) 000B24FFF123 |  |
| Erro de chave de acesso | Digite a chave de acesso exibida na tela do áudio no telefone. |  |
| 5 telefones já estão registrados. | Exclua a lista de telefones parados |  |
| O sistema Bluetooth não pode se comunicar com o telefone. | Consultar a folha IOP ?IOP : Inter-operabilidade |  |
| Não há conexão | O telefone do usuário ou o dispositivo Bluetooth do carro não registrou o dispositivo Bluetooth para conectar | Tente parar novamente |
| O sistema Bluetooth não pode se comunicar com o telefone. | Aguarde 1 minuto, depois tente a conexão novamente ou desligue e ligue o telefone. Consultar a folha IOP |  |
| Não há redial | Problema de sistema do telefone do usuário | Pressione duas vezes o botão Enviar |
| Não aceita chamada | Problema de sistema do telefone do usuário | Consultar a folha IOP |
| Não faz ligação | O telefone do usuário está executando outro menu (internet, mp3, jogo, etc.) | Pare com outros menus, depois configure o modo normal |
| O sistema Bluetooth não pode se comunicar com o telefone | Consultar a folha IOP |  |
