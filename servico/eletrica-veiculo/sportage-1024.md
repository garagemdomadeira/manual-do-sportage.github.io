## Especificações

Unidade de Chave Inteligente

| Itens | Especificação |
| --- | --- |
| Tensão nominal | DC 12V |
| Tensão de operação | DC 9 ~ 16V |
| Temperatura de operação | -22°F ~ 167°F (-30°C ~ 75°C) |
| Carga | Máx. 3mA |

Receptor de RF

| Itens | Especificação |
| --- | --- |
| Frequência | 433 MHz |
| Tipo de antena | FSK (Keying de Deslocamento de Frequência) |

Chave Inteligente Fob

| Itens | Especificação |
| --- | --- |
| Bateria | Bateria de lítio 3V |
| Distância | 30m |
| Vida útil da bateria | Mais de 2 anos. Uma bateria mal descartada pode ser prejudicial ao meio ambiente e à saúde humana. Descarte a bateria de acordo com a lei(s) ou regulamento(s) locais. |
| Push buttons | 4 (Trancar/Desbloquear Porta, Travão Traseiro, Emergência) |
| Frequência (Rx) | 125 KHz |
| Frequência (Tx) | 433.92 MHz |
| Números | 2EA |

Antena

| Itens | Especificação |
| --- | --- |
| Tensão nominal | DC 12V |
| Tensão de operação | DC 9 ~ 16V |
| Temperatura de operação | -22°F ~ 167°F (-30°C ~ 75°C) |
| Frequência | 125 KHz |
| Números | Interior(3EA), Porta(2EA), Bumper(1EA) |
