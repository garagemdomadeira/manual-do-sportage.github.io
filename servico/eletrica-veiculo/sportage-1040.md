## Especificações

Desempenho Elétrico

| Item | Requisito | Observação |
| --- | --- | --- |
| Tensão nominal | DC 12V |  |
| Faixa de tensão de operação | DC 9 ~ 16V | Deve ativar normalmente nessa faixa. |
| Faixa de temperatura de operação | -30°C ~ +80°C | Deve conservar normalmente nessa faixa. |
| Faixa de temperatura de armazenamento | -40°C ~ +85°C |  |
| Umidade máxima em uso | 95% |  |
| Resistência à tensão de alta | 24V/1min, 18V/1hora | Após sobretensão, o comportamento normal. |
| Resistência de isolamento | 100M? ou mais (medido com MEGGER de 500V) | Especificar também partes que isolamento como PCB, revestimento impermeável são necessários. |
| Corrente em repouso | Especificação KEYLESS: 6mA ou menos Especificação SMK: 5,5mA ou menos Não KEYLESS: 4mA ou menos | Medir quando o estado, todos os carregadores de carga de saída estão desligados e não há mudanças nos botões de entrada (incluindo operação TX), continuando 2 segundos. |
| Perda de tensão | 1,2V ou menos | Mas, os terminais B9, B20, C1, C2, C3, C13, C14, C15, C16 são 2,0V ou menos. |
