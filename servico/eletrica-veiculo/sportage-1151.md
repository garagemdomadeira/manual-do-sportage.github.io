## Descrição

Esta função descreve as seguintes características

| – | Detecção de entrada pelo Sensor de Luz Automática. |
| --- | --- |

| – | Geração de dados de Status de Luz Automática Externa. |
| --- | --- |

| – | Envio de Status de Luz Automática Externa. |
| --- | --- |

| – | Controle de Luzes Traseiras pelo Modo de Luz Automática. |
| --- | --- |

| – | Controle de Luzes de Freio Baixo pelo Modo de Luz Automática. |
| --- | --- |

| – | Controle AV de Luzes Traseiras pelo nível do Sensor de Luz Automática. |
| --- | --- |

| • | Diagrama de Estado do Modo de Luz Automática é baseado no nível do Sensor de Luz Automática. |
| --- | --- |

| • | Condição de Energia do Ação de Luz Automática |
| --- | --- |

| – | Quando os estados dos terminais ACC, IGN, START, o Sensor de Luz Automática opera. |
| --- | --- |
