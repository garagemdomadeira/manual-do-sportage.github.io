# Kia Sportage SL: Motorização NU / Troubleshooting

[Home](../../index.md) / [Kia Sportage SL Service & Repair Manual](../sportage-482.md) / [Motorização NU](index.md) / Troubleshooting

## Diagnóstico

Sistema de Ignição

| Sintoma | Área Suspeita | Remédio |
| --- | --- | --- |
| Motor não arranca ou é difícil de arrancar (Crank OK) | Interruptor de ignição | Inspeção do interruptor de ignição, ou substituição conforme necessário |
| Bobina de ignição | Inspeção da bobina de ignição, ou substituição conforme necessário |  |
| Parafusos de ignição | Inspeção dos parafusos de ignição, ou substituição conforme necessário |  |
| Conexões de ignição desconectadas ou danificadas | Reparo das conexões, ou substituição conforme necessário |  |
| Velocidade de rotação irregular ou estagnação | Conexões de ignição | Reparo das conexões, ou substituição conforme necessário |
| Parafusos de ignição e cabos de parafusos de ignição | Inspeção dos parafusos de ignição / cabo, ou substituição conforme necessário |  |
| Conexões de ignição | Reparo das conexões, ou substituição conforme necessário |  |
| Baixa economia de combustível | Parafusos de ignição e cabos de parafusos de ignição | Inspeção dos parafusos de ignição / cabo, ou substituição conforme necessário |

Sistema de Carregamento

| Sintoma | Área Suspeita | Remédio |
| --- | --- | --- |
| Indicador de carregamento não acende com chave do veículo "ON" e motor desligado. | Fio queimado | Verificar os fusos |
| Luz queimada | Substituição da luz |  |
| Conexão de fiação solta | Ajuste a conexão solta |  |
| Regulador de tensão eletrônico | Se a luz se apagar, substituir o regulador de tensão. |  |
| Indicador de carregamento não se apaga com motor em funcionamento. (Bateria requer recarga frequente) | Cinto de transmissão solto ou gasto | Ajuste a tensão do cinto ou substitua o cinto |
| Conexão de fiação da bateria solta, corroída ou gasta | Inspeção da conexão do fio, reparo ou substituição do fio |  |
| Regulador de tensão eletrônico ou alternador | Se a luz se apagar, substitua o regulador de tensão ou o alternador |  |
| Fiação | Reparo ou substituição do fio |  |
| Sobrecarregamento | Regulador de tensão eletrônico | Se a luz se apagar, substitua o regulador de tensão. |
| Fio de medição de tensão | Reparo ou substituição do fio |  |
| Descarga | Cinto de transmissão solto ou gasto | Ajuste a tensão do cinto ou substitua o cinto |
| Conexão de fiação solta ou curto-circuito | Inspeção da conexão do fio, reparo ou substituição do fio |  |
| Regulador de tensão eletrônico ou alternador | Se a luz se apagar, substitua o regulador de tensão ou o alternador |  |
| Bateria com mau contato | Inspeção do contato ou reparo |  |
| Bateria gasta | Substituição da bateria |  |

Sistema de Arranque

| Sintoma | Área Suspeita | Remédio |
| --- | --- | --- |
| Motor não crava | Carregamento da bateria baixo | Carregamento ou substituição da bateria |
| Conexões de fiação da bateria soltas, corroídas ou gastos | Reparo ou substituição das conexões |  |
| Interruptor de transmissão de caixa de câmbio (apenas veículos com transmissão automática) | Consultar grupo de transmissão automática |  |
| Fio queimado | Substituição do fio |  |
| Motorista de arranque defeituoso | Substituição |  |
| Interruptor de ignição defeituoso | Substituição |  |
| Motor crava lentamente | Carregamento da bateria baixo | Carregamento ou substituição da bateria |
| Conexões de fiação da bateria soltas, corroídas ou gastos | Reparo ou substituição das conexões |  |
| Motorista de arranque defeituoso | Substituição |  |
| Motorista de arranque mantém-se ligado | Motorista de arranque defeituoso | Substituição |

| Iniciador roda, mas o motor não gira | Curto no fiação | Reparar ou substituir a fiação |
| Dentes do engradeiro danificados ou motor do iniciador | Substituir |  |
| Dentes do anel danificados | Substituir a roda dentada ou conversor de torque |  |
