## Diagnóstico

| Sintoma | Área Suspeita | Remédio |
| --- | --- | --- |
| O indicador de carregamento não acende com chave do ignição "ON" e motor desligado. | Fio quebrado | Verificar fusíveis |
| Luz queimada | Substituir a luz |  |
| Conexão de fiação solta | Tensar a conexão solta |  |
| Regulador de tensão eletrônico | Desconectar o regulador de tensão para ver se a luz se apaga. Se a luz se apagar, substituir o regulador de tensão. |  |
| O indicador de carregamento não se apaga com motor em funcionamento. (Bateria requer recarga frequente) | Cinto de transmissão solto ou gasto | Ajustar a tensão do cinto ou substituir o cinto |
| Conexão do cabo de bateria solta, corroída ou gasto | Inspeção da conexão do cabo, reparo ou substituição do cabo |  |
| Regulador de tensão eletrônico ou alternador | Desconectar o regulador de tensão ou alternador para ver se a luz se apaga. Se a luz se apagar, substituir o regulador de tensão. |  |
| Fiação | Reparo ou substituição da fiação |  |
| Sobrecarregamento | Regulador de tensão eletrônico | Desconectar o regulador de tensão para ver se a luz se apaga. Se a luz se apagar, substituir o regulador de tensão. |
| Fio de sensação de tensão | Reparo ou substituição da fiação |  |
| Descarga | Cinto de transmissão solto ou gasto | Ajustar a tensão do cinto ou substituir o cinto |
| Conexão de fiação solta ou curto-circuito | Inspeção da conexão de fiação, reparo ou substituição da fiação |  |
| Regulador de tensão eletrônico ou alternador | Desconectar o regulador de tensão ou alternador para ver se a luz se apaga. Se a luz se apagar, substituir o regulador de tensão. |  |
| Pobre conexão de terra | Inspeção da conexão de terra ou reparo |  |
| Bateria gasta | Substituir a bateria |  |
