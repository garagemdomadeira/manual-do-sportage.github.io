## Diagnóstico

| Sintoma | Área Suspeita | Remédio |
| --- | --- | --- |
| Perda de água do teto panorâmico | Gilete do teto com borracha de vedação deteriorada | Substituir |
| Distância excessiva entre o teto e o corpo e ajuste inadequado da borracha de vedação | Ajustar |  |
| Ruído de vento ao redor do teto panorâmico | Ajuste ou substituição de defletor solto ou deformado, gaps na obra do corpo | Retorcer, ajustar ou substituir |
| Som ouvido ao abrir/fechar o teto panorâmico | Partículas estranhas presas na guia | Verificar a correia de transmissão e as guias para partículas estranhas |
| Guias soltos e teto | Retorcer |  |
| Motor funciona, mas o teto panorâmico não se move ou se move apenas parcialmente | Partículas estranhas presas na guia | Ajustar ou substituir |
| Engajamento incorreto do pinhão do motor com a correia de transmissão |  |  |
| Força de deslizamento do motor diminuída |  |  |
| Resistência aumentada no deslizamento do teto panorâmico ou interferência do teto panorâmico com as correias de transmissão, borracha de vedação, etc. devido a ajuste inadequado do teto panorâmico |  |  |
| Som no motor (ruído de deslizamento do motor quando o teto panorâmico está completamente aberto ou fechado não é um ruído incomum) | Engajamento incorreto do pinhão do motor com a correia de transmissão | Verificar a instalação do pinhão e retorcer o motor |
| Borracha do motor usada ou danificada | Substituir a montagem do motor |  |
| Correia de transmissão usada ou deformada | Substituir |  |
| Vidro da porta não opera de cima para baixo | Instalação incorreta do vidro da porta | Ajustar a posição |
| Borda defeituosa ou defeituosa do regulador ou regulador | Corrigir ou substituir |  |
| Porta não abre ou fecha completamente | Instalação incorreta da porta | Ajustar a posição |
| Montagem do check da porta defeituosa | Corrigir ou substituir |  |
| Aros da porta precisam de graxa | Aplicar graxa |  |
| Capô não abre ou fecha completamente | Alinhamento do estribo e travamento inadequado | Ajustar |
| Instalação incorreta do capô | Ajustar |  |
| Altura do bico do capô defeituosa | Ajustar |  |
| Perda de água através do vidro da frente e do vidro traseiro | Borracha defeituosa | Preencher com selante |
| Borda defeituosa | Corrigir |  |
