# Kia Sportage: Sistema ETC (Electronic Throttle Control): Diagnóstico

[Home](../../index.md) / [Manual de Serviço e Reparo do Kia Sportage SL](../sportage-482.md) / [Controle do Motor / Sistema de Combustível](sportage-582.md) / [Sistema de Controle do Motor](sportage-587.md) / Sistema ETC (Electronic Throttle Control): Diagnóstico

## Modo de Segurança

| Item | Modo de Segurança |  |
| --- | --- | --- |
| Motor ETC | Valvula da admissão travada em 5° |  |
| TPS | Falha no TPS 1 | O ECM verifica o TPS2 |
| Falha no TPS 2 | O ECM verifica o TPS1 |  |
| Falha no TPS 1,2 | Valvula da admissão travada em 5° |  |
| APS | Falha no APS 1 | O ECM verifica o APS 2 |
| Falha no APS 2 | O ECM verifica o APS 1 |  |
| Falha no APS 1,2 | Valvula da admissão travada em 5° |  |

> **Nota**
>
> - Quando a valvula da admissão estiver travada em 5°, a velocidade do motor será limitada a menos de 1.500 rpm e a velocidade do veículo a no máximo 40 ~ 50 km/h (25 ~ 31 mph)
