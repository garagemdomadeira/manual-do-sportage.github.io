## Diagnóstico de Aquecimento do Motor

| Inspeção | Correção |  |
| --- | --- | --- |
| Inspeção visual | Inspeção para falta de líquido refrigerante no tanque de reservatório. | Reinspeção após a reposição do líquido refrigerante. |
| Inspeção para sujeira do líquido refrigerante após a remoção do tampão do radiador. Seja cuidadoso ao remover o tampão do radiador de um veículo aquecido. | Reinspeção após a substituição do líquido refrigerante. |  |
| Seja cuidadoso ao remover o tampão do radiador de um veículo aquecido. |  |  |
| Inspeção para vazamento e conexões soltas de mangueiras de líquido refrigerante (mangueira do radiador, mangueira do aquecedor, mangueira do cooler de óleo, etc.). | Reinspeção para vazamento após a reinstalação das mangueiras e das engates. |  |
| Inspeção para vazamento na montagem da conexão de entrada de água. | Reinspeção para vazamento após a substituição do anel O-ring. |  |
| Reinspeção para vazamento após a apertar para a torque especificada. |  |  |
| Inspeção da mangueira de transmissão (para o funcionamento normal do bomba de água). | Ajuste a tensão da mangueira de transmissão ou substitua. |  |
| Inspeção para vazamento na montagem do anel de montagem da bomba de água. | Reinspeção para vazamento após a substituição do anel. |  |
| Reinspeição para vazamento após a apertar para a torque especificada. |  |  |
| Inspeção da conexão e pinos do sensor de temperatura do líquido refrigerante, do conector e do pinos do ventilador de resfriamento. | Reinstale a conexão solta. |  |
| Substitua a parte relevante se o pin do conector estiver danificado. |  |  |
| Inspeção do status de operação do ventilador de resfriamento. - Verifique o status de operação ligando e desligando o controle do aquecedor A/C. Não funcionará em temperatura ambiente fria. | Verifique o status de montagem do cabo de terra. |  |
| Não funcionará em temperatura ambiente fria. |  |  |
| Dispositivo de diagnóstico | Inspeção do código de diagnóstico usando KDS/GDS. | Verifique o sensor de temperatura do líquido refrigerante, a ligação, o conector, etc. |
| Inspeção do módulo | Inspeção do impelor da bomba de água. | Substitua a bomba de água. |
| Inspeção de materiais estranhos e status do válvula do termostato. | Inspeção do módulo após a remoção dos materiais estranhos. |  |
| Inspeção de válvula do termostato presa. - Immerza o termostato em água aquecida a mais de 95°C (203°F), então aqueça por pelo menos 3 minutos para verificar o levantamento da válvula. • Não use água abaixo de 95°C (203°F). • Não aqueça diretamente o módulo, pois isso danificará o termostato. | Verifique o levantamento da válvula. - Substitua o termostato se o levantamento da válvula estiver abaixo da especificação ou se a válvula estiver presa. |  |
| • Não use água abaixo de 95°C (203°F). |  |  |
| • Não aqueça diretamente o módulo, pois isso danificará o termostato. |  |  |
