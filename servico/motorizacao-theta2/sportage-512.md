## Diagnóstico

| Sintomas | Causas Possíveis | Remédio |  |  |
| --- | --- | --- | --- | --- |
| Vazamento de líquido de resfriamento | • Do selo do termostato | Verifique os parafusos de montagem | • Verifique o torque dos parafusos de montagem | • Retorque os parafusos e verifique o vazamento novamente. |
| Verifique o selo para danos | • Verifique o selo ou vedante para danos | • Substitua os selos e reutilize o termostato. |  |  |
| Resfriamento excessivo | • Baixa performance do aquecedor (ar frio sai) • Termogauge indica ''LOW'' | Verifique visualmente após remover a tampa do radiador. | • Nível insuficiente de líquido de resfriamento ou vazamento. | • Após repor o líquido de resfriamento, reavalie. |
| Verificação GDS e partida do motor | • Verifique os códigos de diagnóstico (DTCs) • Verifique o desempenho do motor do ventilador conforme a temperatura varia. • Verifique a conexão da embreagem do ventilador ou do motor do ventilador. Nota: Se a embreagem do ventilador estiver sempre conectada, haverá barulho em marcha lenta. | • Verifique o sensor de temperatura do líquido do motor, a fiação e as conexões. • Verifique o motor do ventilador, o relé e a conexão. • Substitua os componentes. |  |  |
| Remova o termostato e inspecione | • Verifique se há poeira ou pedaços de metal na válvula do termostato. • Verifique a aderência do termostato. | • Limpe a válvula do termostato e reutilize o termostato. • Substitua o termostato, se ele não funcionar corretamente. |  |  |
| Aquecimento excessivo | • Motor aquecido demais • Termogauge indica ''HI'' | Verifique visualmente após remover a tampa do radiador. | • Nível insuficiente de líquido de resfriamento ou vazamento. Cuidado: Seja cuidadoso ao remover a tampa do radiador de um veículo aquecido. • Verifique o ar no sistema de resfriamento. | • Após repor o líquido de resfriamento, reavalie. • Verifique as juntas do cabeçote e o torque de montagem dos parafusos. |
| Verificação GDS e partida do motor | • Verifique os códigos de diagnóstico (DTCs) • Verifique o desempenho do motor do ventilador conforme a temperatura varia. • Verifique se a embreagem do ventilador está patinando. • Verifique a aderência ou o impelidor da bomba d'água, se estiver danificado. | • Verifique o sensor de temperatura do líquido de resfriamento do motor, fiação e conectores. • Verifique o motor do ventilador, o relé e o conector. • Substitua a embreagem do ventilador, se não estiver funcionando corretamente. • Substitua a bomba d'água, se não estiver funcionando corretamente. |  |  |
| Mergulhe o termostato em água fervente e inspecione. | • Após remover o termostato, verifique se está funcionando corretamente. Nota: Verifique se o termostato se abre na temperatura de abertura da válvula. | • Substitua o termostato, se não estiver funcionando corretamente. |  |  |
