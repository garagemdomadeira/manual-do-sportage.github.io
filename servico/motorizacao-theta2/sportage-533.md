# Kia Sportage: Diagnóstico

[Início](../../index.md) / [Manual de Serviço e Reparo do Kia Sportage SL](../sportage-482.md) / [Sistema Elétrico do Motor](sportage-530.md) / Diagnóstico

## Diagnóstico

Sistema de Ignição

| Sintoma | Área Suspeita | Remédio |
| --- | --- | --- |
| Motor não arranca ou é difícil de arrancar (Crank OK) | Interruptor de ignição | Inspeção do interruptor de ignição, ou substituição conforme necessário |
| Bobina de ignição | Inspeção da bobina de ignição, ou substituição conforme necessário |  |
| Parafusos de ignição | Inspeção dos parafusos de ignição, ou substituição conforme necessário |  |
| Conexões de ignição desligadas ou quebradas | Reparo das conexões, ou substituição conforme necessário |  |
| Velocidade de rotação irregular ou estagnação | Conexões de ignição | Reparo das conexões, ou substituição conforme necessário |
| Parafusos de ignição e cabos de parafusos de ignição | Inspeção dos parafusos de ignição / cabo, ou substituição conforme necessário |  |
| Conexões de ignição | Reparo das conexões, ou substituição conforme necessário |  |
| Baixa economia de combustível | Parafusos de ignição e cabos de parafusos de ignição | Inspeção dos parafusos de ignição / cabo, ou substituição conforme necessário |

Sistema de Carregamento

| Sintoma | Área Suspeita | Remédio |
| --- | --- | --- |
| Indicador de carregamento não acende com chave do motorista "ON" e motor desligado. | Fio queimado | Verifique os fusíveis |
| Luz queimada | Substituição da luz |  |
| Conexão de fiação solta | Apertar a conexão solta |  |
| Regulador de tensão eletrônico | Substituição do regulador de tensão |  |
| Indicador de carregamento não apaga com motor ligado. (Bateria requer recarga frequente) | Cinto de transmissão solto ou gasto | Ajuste a tensão do cinto ou substitua o cinto |
| Conexão de fiação da bateria solta, corroída ou gasta | Verifique a conexão do fio, reparo ou substituição do fio |  |
| Regulador de tensão eletrônico ou alternador | Substituição do regulador de tensão ou alternador |  |
| Fiação | Reparo ou substituição da fiação |  |
| Sobrecarregamento | Regulador de tensão eletrônico | Substituição do regulador de tensão |
| Fio de sensação de tensão | Reparo ou substituição da fiação |  |
| Descarga | Cinto de transmissão solto ou gasto | Ajuste a tensão do cinto ou substitua o cinto |
| Conexão de fiação solta ou curto-circuito | Verifique a conexão do fio, reparo ou substituição da fiação |  |
| Regulador de tensão eletrônico ou alternador | Substituição do regulador de tensão ou alternador |  |
| Mal-terçado | Verifique a terça, ou reparo |  |
| Bateria gasta | Substituição da bateria |  |

Sistema de Arranque

| Sintoma | Área Suspeita | Remédio |
| --- | --- | --- |
| Motor não crava | Carregamento da bateria baixo | Carregamento ou substituição da bateria |
| Conexões de fiação da bateria soltas, corroídas ou gastos | Reparo ou substituição das conexões |  |
| Interruptor de transmissão de caixa de câmbio (apenas veículos com transmissão automática) | Consulte o grupo de transmissão automática |  |
| Fusível queimado | Substituição do fusível |  |
| Arranque defeituoso | Substituição |  |
| Interruptor de ignição defeituoso | Substituição |  |
| Motor crava lentamente | Carregamento da bateria baixo | Carregamento ou substituição da bateria |
| Conexões de fiação da bateria soltas, corroídas ou gastos | Reparo ou substituição das conexões |  |
| Arranque defeituoso | Substituição |  |
| Arranque continuo | Arranque | Substituição |
| Interruptor de ignição | Substituição |  |
| Arranque gira mas motor não crava | Curto na fiação | Reparo da fiação |

| Dente do engraxador quebrado | Substituir a roda de transmissão ou o conversor de torque |  |
